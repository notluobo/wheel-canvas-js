# 社区行为准则

[English](../../.github/CODE_OF_CONDUCT.md) · 简体中文

我们致力于提供友善、专业、无骚扰的协作环境，不因年龄、身体差异、族群、性别表达、经验水平、国籍、外貌、宗教或性取向而区别对待参与者。

参与者应：

- 尊重不同观点，围绕事实、代码和用户影响讨论；
- 提供可复现信息，接受建设性反馈；
- 避免侮辱、骚扰、威胁、泄露他人隐私和未经允许的商业推广；
- 在发现不当行为时停止扩散，并通过维护者公布的私密渠道报告。

维护者可以编辑或删除违反准则的评论、提交和 issue，并根据严重程度进行警告、临时限制或永久禁止参与。维护者也应解释执行决定，除非公开说明会伤害报告人或泄露隐私。

公开仓库建立后，项目所有者应在本文件补充可用的私密联系渠道。
