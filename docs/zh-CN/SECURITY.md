# 安全政策

[English](../../.github/SECURITY.md) · 简体中文

## 支持范围

安全修复只进入最新发布版本。尚未发布修复时，维护者会在变更记录和安全公告中说明受影响版本。

## 报告漏洞

请不要在公开 issue 中披露尚未修复的漏洞。请通过 [GitHub 私密漏洞报告](https://github.com/notluobo/wheel-canvas-js/security/advisories/new)提交；项目所有者必须在正式发布前启用并持续开放该功能。

本项目不会虚构维护者邮箱。如果私密表单不可用，可以创建一个不包含漏洞细节的 issue，请维护者启用私密报告；不得在该 issue 中公开漏洞内容。

报告应包含受影响版本、复现步骤、影响范围和可行的缓解方案。维护者确认后再协商公开时间。

## 抽奖安全边界

本库是渲染和动画工具，不是可信随机数、库存或支付系统。奖品具有资金或权益价值时，服务端必须完成身份校验、幂等、库存扣减、审计和中奖决策；浏览器只接收结果下标并调用 `stop(index)`。
