# Changelog

[English](../../CHANGELOG.md) · 简体中文

本项目遵循 [Semantic Versioning](https://semver.org/lang/zh-CN/)。

## 1.0.0 - 2026-08-24

### Changed

- 新增默认简体中文 README、英文备用 README、配套双语文档和可切换语言的工作台，并加入双语一致性检查。
- 项目正式命名为 `WheelCanvasJS`，npm 包名统一为 `wheel-canvas-js`。
- 浏览器全局入口统一为 `WheelCanvasJS.WheelCanvas`，模块入口导出 `WheelCanvas` 和 `createWheelCanvas`。
- 发布文件统一为 `wheel-canvas-js.umd.js`、`wheel-canvas-js.esm.mjs` 与 `wheel-canvas-js.d.*`，不再发布通用的 `index.*` 入口名称。

### Added

- 增加可选 `feedback` 适配层：扇区经过声、中奖声、触发间隔和成功结束庆祝均可配置，适配器异常与抽奖生命周期隔离。
- 首页增加 UI SFX 声音包/语义声音/音量/预听控件，以及可关闭且尊重减少动态效果偏好的 canvas-confetti 庆祝控件。
- 工作台增加带版本与异常降级的浏览器本地配置自动保存、恢复、状态提示和实时预览重置入口。
- 首页升级为工具优先的双栏工作台：转盘与完整设置在首屏同时可见，并提供无阴影的中性色设计和移动端单栏降级。

- 零运行时依赖的原生 JavaScript `WheelCanvas` 实现。
- UMD、CommonJS、ESM 和 TypeScript 入口。
- `useGraphicWeight`、`displayWeight` 与 `graphicWeightSource` 图形权重配置。
- 鼠标、Enter 和空格键操作，以及可配置的 Canvas 无障碍标签。
- 图片去重加载、独立 formatter 缓存和响应式缓存失效。
- CJS/ESM/浏览器全局、类型、兼容性、动画和边界回归测试。
- EditorConfig、Prettier、ESLint 和 CI 组成的四空格编码规范检查。
- 响应式产品首页、快速开始、交互示例、配置参考和 JSON Playground。
- 可配置的中心、外置和隐藏指针，支持上下左右、任意角度、单边留白、主体、固定座、默认关闭的可选阴影和自定义渲染。
- `flapper`、`wedge`、`needle`、`pin`、`glass`、`jewel` 等外置指针预设。
- 带曲线主体、偏轴高光、暗面和金属固定座的 `classic` 外置指针预设。
- 默认 `minimal` 极简外置箭头，以及可实时调整的尖端深入距离。
- 各指针预设的独立默认比例、仅主体透明的 glass 和水滴形 pin。
- 首页完整配置工作台，可实时调整指针、外框、内框、扇区、中心、文字、动画与物理，并通过高级 JSON 编辑全部可序列化配置。
- 中心指针支持独立造型、角度、尺寸、描边与径向位置；中心和外置指针扩展为 21 种内置造型。
- 新增 `soft`、`tab`、`dart`、`shield`、`ribbon` 五种指针，以及跟随当前扇区颜色和可调阻尼回弹反馈。
- 首页支持奖品纯文字、纯图片、图文混排、中心 Logo、图片 URL、本地上传、尺寸、位置与跨域模式配置。
- 图片上传增加 MIME 类型与 5 MiB 大小限制，空奖品和无有效权重场景提供安全回退。
- 中心按钮显示、文字显示、半径、边框、透明度与真正垂直对齐配置；官方视觉默认无阴影。
- 扇区和按钮文字的横排/竖排、显示、对齐、自动/手动换行、裁剪与自定义省略标记。
- 图片装饰、文字排版、中心按钮、落点速度示例和完整能力清单。
- 鼠标、触控笔和触屏拖拽物理旋转，使用加权速度回归、滚动阻力、黏性阻尼和帧率无关小步积分。
- 禁止释放后提速的连续目标制动、异步等待策略、严格后端下标验证和手势取消生命周期。
- 低速长距离 C² 加速度衔接与渐进制动、结果错误自然滑停，以及可配置的立即停止错误策略。
- 任意角度指针安全区、可选径向阴影换算和异常隔离的自定义指针渲染器。
- `spin(velocity)` 编程式惯性旋转方法，速度单位为度/秒。
- 产品竞品审计、核心/插件/工具站边界和分阶段发布门槛。

### Fixed

- 翻译前统一处理多行 DOM 文本中的排版空白，并在英文首屏翻译完成前暂缓显示页面，避免源码换行和首屏时序暴露中文片段。
- 顶部双语言文字链接改为单个无障碍地球按钮，仅显示当前语言并直接切换到另一语言。
- 英文 DOM 翻译改为等待 `DOMContentLoaded` 后一次完成，修复浏览器流式解析文字节点时产生的中英文混排。
- 缓存稳定的扇区布局、外置指针几何与文字换行结果，避免动画每帧重复计算；Web Font 加载和响应式配置变化会精确失效缓存。
- 增加可配置的 `maxDpr` 与 `maxCanvasPixels` backing-store 预算，降低高 DPR 超大画布的内存风险。
- 主画布与离屏画布统一使用像素预算，并通过 `imageConcurrency` 限制批量图片加载峰值。
- 解耦外置指针和转盘尺寸：新增 `fit`、`stable`、`overlay` 三种布局，稳定模式调整指针时不再改变轮盘半径。
- 外置指针示例改用绝对像素尺寸，调整画布时不再连带改变指针造型；尺寸控制范围与实际引擎限制保持一致。
- 中心指针默认与中心按钮一体绘制、继承中心颜色和边框，并允许通过 `fused: false` 恢复独立样式。
- 修复窄屏 Grid 最小内容宽度导致演示卡片和轮盘被右侧裁切的问题。
- 修复示例页 Tabs 缺少键盘语义及 Playground 永久拦截 Tab 焦点的问题。
- 修复旋转快照未深复制指针渐变配置的问题。
- 修复中心独立指针仍受按钮半径、可见性、透明度和阴影影响的问题，并增加独立尺寸基准。
- 修复简单控件覆盖高级指针字段、响应式单位、多层图片和奖品独立字体配置的问题。
- 修复销毁发生在创建、缩放、手势和自定义渲染回调中时仍继续注册监听器、改变角度或绘制的问题。
- 修复极端外置指针在 `fit` 布局下迭代不足导致的边缘裁切，以及现代透明 CSS 颜色识别。
- 修复运行中按钮视觉未冻结、结束后新按钮样式未重绘，以及图片无法无损隐藏的问题。
- 修复动态 `ariaLabel`、无操作 Canvas 的假按钮语义、忙碌状态和实时奖品无障碍列表不同步的问题。
- 修复极窄文本的省略标记越界，并让窄屏配置面板取消嵌套滚动、改用单列触控布局。
- 首页默认指针改为圆形中心按钮与向上三角指针融合轮廓。
- 收紧融合三角的光学比例，统一转盘默认色板与边框层级，并将完整配置改为渐进展开，避免首屏呈现调试工具感。
- 首页默认改用更窄、更短的 `minimal` 中心融合箭头，去除不必要的机械造型，其他指针仍可按需切换。
- 新增 `fusionStyle: 'droplet'` 中心水滴轮廓，用一条连续路径融合圆形按钮和尖端；首页默认缩小中心比例并改用白色单边框。
- 修复原生分层中心指针被按钮圆形边框横穿而出现内部白线的问题，只保留融合造型的外轮廓。
- 关闭内置箭头默认的白色装饰线，并修复窄容器二次缩放 Canvas 与自动 DPR 固化造成的整体模糊问题。
- 新增中心与外置指针 `cornerRadius` 轮廓圆角配置，首页可实时调整，默认使用克制的 3px 圆角。

### Compatibility

- 保留早期参考实现的主要配置语义、生命周期和公开辅助方法。
- 原 `play()` / `stop(index)` 流程继续使用初速度连续的 Hermite 曲线；物理滑动使用独立的连续制动状态，不改变旧动画配置语义。

### Security

- 文档明确说明高价值抽奖必须由可信后端决定结果。
