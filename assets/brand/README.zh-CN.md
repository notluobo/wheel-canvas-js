# WheelCanvasJS 品牌资产

[English](./README.md) · 简体中文

`wheel-canvas-js-logo.png` 是 WheelCanvasJS 的标准项目 Logo。

## 文件规格

- 格式：PNG（RGBA 透明通道）
- 原始尺寸：192 × 192 px
- 用途：项目首页、README、站点图标和开源仓库展示
- 首页显示尺寸：桌面端 42 × 42 CSS px，窄屏 38 × 38 CSS px
- README 显示尺寸：160 × 160 CSS px

原始文件作为唯一标准源文件保留。浏览器显示时按比例缩放，不裁切、不拉伸、不增加阴影，也不在 Logo 内部叠加文字。项目名称应作为独立文本放在 Logo 旁边，以保持小尺寸下的可读性和无障碍语义。

该资产随项目一起发布，分发信息见项目根目录的 `LICENSE` 与 `NOTICE`。
