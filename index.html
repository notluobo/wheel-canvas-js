从零开始使用 WheelCanvasJS

零运行时依赖、配置驱动的 Canvas 转盘。下面从引入文件开始，完整讲解内容、权重、指针、物理旋转、事件、性能和上线检查。

01

快速开始

下载发布包中的 wheel-canvas-js.umd.js ，按顺序放入页面。UMD 入口会暴露全局对象 WheelCanvasJS ，不需要 Vue、React 或其他运行时。

最低准备：一个有明确尺寸的容器、核心脚本、奖项数组，以及一个 WheelCanvas 实例。
example.html 

                                        <div id="wheel" style="width: 420px; max-width: 100%"></div>
                                        <button id="spin" type="button">开始抽奖</button>

                                        <script src="./wheel-canvas-js.umd.js"></script>
                                        <script>
                                            const wheel = new WheelCanvasJS.WheelCanvas('#wheel', {
                                                width: '100%',
                                                height: '420px',
                                                prizes: [
                                                    { background: '#ede9fe', fonts: [{ text: '一等奖' }] },
                                                    { background: '#dff4ec', fonts: [{ text: '二等奖' }] },
                                                    { background: '#fde7d8', fonts: [{ text: '谢谢参与' }] },
                                                ],
                                                buttons: [{ radius: '18%', background: '#6047dd', fonts: [{ text: '开始' }] }],
                                                end(prize) {
                                                    alert(`抽中：${prize.fonts?.[0]?.text || '未命名奖项'}`)
                                                },
                                            })

                                            document.querySelector('#spin').addEventListener('click', () => {
                                                wheel.play()
                                                setTimeout(() => wheel.stop(), 1200)
                                            })
                                        </script>

terminal + app.js

02

理解配置结构

常用配置按职责分成六部分，辅助声音和彩带不属于核心中奖计算。

prizes 奖项、颜色、文字、图片和权重
buttons 中心按钮、文字和 Logo
blocks 外圈、内圈和多层边框
pointer 中心、外置、隐藏及 21 种造型
defaultConfig 速度、停靠范围、图形权重和质量
physics 拖动、惯性、阻力和受控落点

03

奖项、文字与图片

每个奖项可包含多层文字和多张图片。尺寸、位置支持数字、px 和百分比；百分比会随转盘尺寸变化。长文字可通过换行、行数和省略策略约束。

图文奖项 

                                        {
                                            name: 'gift-card',
                                            range: 10,
                                            displayWeight: 2,
                                            background: '#ede9fe',
                                            fonts: [{
                                                text: '礼品卡 100 元',
                                                fontColor: '#211944',
                                                fontSize: '3.8%',
                                                top: '18%',
                                                lengthLimit: '82%',
                                                lineClamp: 2,
                                                textOverflow: 'ellipsis',
                                                orientation: 'horizontal',
                                            }],
                                            imgs: [{
                                                src: './gift.png',
                                                width: '18%',
                                                top: '52%',
                                                crossOrigin: 'anonymous',
                                            }],
                                        }
  • 同源图片可直接使用；跨域图片需要服务器允许 CORS。
  • 修改图片地址或 formatter 后，引擎会重新加载，不复用错误结果。
  • 图片加载完成以 await wheel.ready 为准。
  • 大量 Data URL 会放大 JSON 和内存，应优先使用经过压缩的资源地址。
04

中奖权重与图形权重

range 决定随机抽中的概率； displayWeight 只决定扇区面积。两者彼此独立，避免“看起来大就一定更容易中奖”的误解。

开启不等宽扇区 

                                        defaultConfig: {
                                            useGraphicWeight: true,
                                            graphicWeightSource: 'displayWeight',
                                        },
                                        prizes: [
                                            { range: 1, displayWeight: 4, fonts: [{ text: '视觉更大' }] },
                                            { range: 9, displayWeight: 1, fonts: [{ text: '中奖率更高' }] },
                                        ]
真实商业抽奖应由可信后端决定结果，再调用 stop(index) ；不要把浏览器端随机数作为安全抽奖凭证。
05

指针和中心按钮

指针支持中心、上/右/下/左外置、任意角度及隐藏。所有预设支持尺寸、颜色、扇区跟色、圆角与回弹。

中心自适应融合 

                                        pointer: {
                                            type: 'center',
                                            preset: 'arrow',
                                            fused: true,
                                            fusionStyle: 'adaptive',
                                            colorSource: 'currentPrize',
                                            width: '82%',
                                            height: '128%',
                                            cornerRadius: 3,
                                            shadow: false,
                                        }
融合模式 适用场景
adaptive 保留所选造型，与中心按钮形成无内部描边的一体轮廓
droplet 固定水滴形连续轮廓，不随 preset 改变形状
layered 中心圆和箭头分别着色、分别描边

外置指针使用 layout: 'stable' 可避免调整指针时缩小转盘；使用 fit 可让极端尺寸完整避让。

06

开始、停止与后端结果

受控抽奖 

                                        async function draw() {
                                            if (wheel.isRunning()) return
                                            wheel.play()

                                            try {
                                                const response = await fetch('/api/draw', { method: 'POST' })
                                                if (!response.ok) throw new Error('抽奖接口不可用')
                                                const { index } = await response.json()
                                                wheel.stop(index)
                                            } catch (error) {
                                                wheel.stop(-1)
                                                console.error(error)
                                            }
                                        }
  • play() 进入加速和巡航状态。
  • stop(index) 精确落到指定奖项。
  • stop() 按 range 权重选择奖项。
  • stop(-1) 取消本次抽奖，不触发中奖回调。
  • 运行时不要增删或重排奖项；核心会拒绝不一致结果。
07

真实滑动物理

用户可以直接拖动轮盘并释放。引擎使用时间窗口估算角速度、固定子步积分阻力，并在指定结果下生成连续减速轨迹。

自然甩动 

                                        physics: {
                                            enabled: true,
                                            dragFrom: 'wheel',
                                            direction: 'both',
                                            sensitivity: 1,
                                            minVelocity: 36,
                                            maxVelocity: 1800,
                                            friction: 24,
                                            drag: 0.68,
                                            stopVelocity: 3,
                                            onRelease(detail) {
                                                console.log('释放速度', detail.velocity)
                                                // 不返回下标：自然停靠
                                                // 返回下标或 Promise：受控落点
                                            },
                                        }

onRelease 返回奖项下标时，轨迹会保持位置、速度和加速度连续，并遵守最大制动力与 jerk 限制；返回 Promise 时可等待后端结果。

08

生命周期、声音和彩带

核心不打包音频文件和烟花库。可选反馈通过适配器注入，失败不会改变中奖结果。

生命周期与反馈适配器 

                                        {
                                            start() {
                                                console.log('开始旋转')
                                            },
                                            onCurrentChange(prize, index) {
                                                console.log('指针经过', index, prize)
                                            },
                                            end(prize) {
                                                console.log('最终结果', prize)
                                            },
                                            error(error) {
                                                console.error(error.name, error.message)
                                            },
                                            feedback: {
                                                sound: {
                                                    enabled: true,
                                                    play(cue, detail) {
                                                        audioAdapter.play(cue, detail)
                                                    },
                                                },
                                                celebration: {
                                                    enabled: true,
                                                    fire(style, detail) {
                                                        confettiAdapter.fire(style, detail)
                                                    },
                                                },
                                            },
                                        }

音频必须由用户手势解锁；请尊重系统“减少动态效果”，并对 tick 音效设置最小间隔，避免高速旋转时创建过多音频节点。

09

响应式、清晰度与性能

  • 容器必须具有可计算宽度；推荐转盘宽度使用 100% 。
  • 百分比字号、图片和中心尺寸随可绘制直径缩放；px 指针保持绝对尺寸。
  • maxDpr 限制高分屏倍率， maxCanvasPixels 防止超大画布占用过多内存。
  • 窗口、父容器和设备像素比变化时调用 wheel.resize() 。
  • 销毁组件或切换页面时调用 wheel.destroy() ，清理监听器、动画和资源。

11

常见问题

页面没有显示转盘

确认先加载 wheel-canvas-js.umd.js，再创建实例；容器需要可计算宽度，并检查控制台是否有选择器或图片错误。

画面模糊或占用过高

不要用 CSS 强行二次缩放 Canvas；合理设置 maxDpr 和 maxCanvasPixels，并在容器尺寸改变后调用 resize。

中奖概率与扇区大小不一致

这是双权重的预期行为：range 控制概率，displayWeight 控制面积。关闭 useGraphicWeight 后扇区恢复等分。

跨域图片无法导出或显示

图片服务器必须返回允许当前站点的 CORS 响应头，并在图片配置中设置 crossOrigin: 'anonymous'。

应该查看哪里获得全部字段？

查看随包发布的 README.md 、 docs/config.md 、 docs/CAPABILITIES.md 和 wheel-canvas-js.d.ts 。类型文件是 API 契约，实际运行入口是 wheel-canvas-js.umd.js 或 wheel-canvas-js.esm.mjs。
